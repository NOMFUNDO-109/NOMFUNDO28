# NOMFUNDO28 — Portfolio

This repository contains the static portfolio site for Nomfundo Makhoba.

Files added/updated:
- index.html (site content, projects, education, certifications)
- styles.css
- scripts.js
- assets/profile.svg
- assets/projects/* (project placeholder images)

How to publish (GitHub Pages):
1. If the repository is public, go to Settings → Pages and set the source branch to `main` and folder `/ (root)`.
2. Wait a minute for the site to be published. The site URL will be shown in the Pages settings.

Download a zip of the site (direct link to main branch zip):
https://github.com/NOMFUNDO-109/NOMFUNDO28/archive/refs/heads/main.zip
